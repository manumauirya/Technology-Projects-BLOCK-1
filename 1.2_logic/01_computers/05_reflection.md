# Part 5 – Final Reflection
Write **200–300 words** describing your learning experience during this lab.


​In this lab, I learned a lot about computer parts and how they work together. Before this, I only knew the basics like the monitor,
keyboard, mouse, and main computer box. Seeing the inside of a computer helped me understand how everything actually works. The surprising
part was seeing how many small parts are inside and how each one has a specific job. I learned about the motherboard, RAM, processor
hard drive, power supply, and cooling fan. Learning about the motherboard was new to me—it connects all the parts so they can talk to each other. 
I also learned that RAM temporarily holds information while the computer is on.The main challenge was telling the parts apart because 
some looked very similar at first. I also had to be careful handling them so nothing broke. But as I spent more time learning what each 
part does, it got much easier to recognize them. We also looked at smaller computer boards like the Raspberry Pi.
Unlike regular desktop computers, these are built for simple, specific tasks. They put many parts onto one small board to 
save space, cut costs, and use less power. You can find them in things like smart TVs and home security systems.
​Overall, getting hands-on practice helped me understand the lessons much better. I feel much more comfortable with 
computer hardware now and ready to learn more in the future.

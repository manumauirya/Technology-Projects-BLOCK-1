# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.

ans - The hardware is the physical part of computer which help user to interact with computer functions. Hardware are visual,touchable and portable.
      Hardware used to give and take command to computer operating system for further operation. Hardware used for all computer components such as input , 
      processing ,storage and output. The examples of hardware: mouse , keyboard , memory etc .


## Explain Software
Write **at least 50 words** explaining what software is.

ans - The software is logical part of computer which control and manage the computer system .Software is set of instruction and program so that it is neither 
      touchable nor portable. It helps hardware to connect with computer . It is categories in two types ; system software and application software. 
      Operating system, excell, word , powerpoint, ... are examples of software .

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.

ans - Hardware and Software does Interact by :
When we click an application, the software generates commands and operating system acts as a bridge between applications and hardware.
OS manages resources such as memory, storage, and input/output devices .The CPU processes calculations and logical operations. RAM temporarily 
stores data needed by running programs. Storage devices save files and programs permanently.The hardware sends the processed data back. The software
displays the results on the screen or performs the requested action.

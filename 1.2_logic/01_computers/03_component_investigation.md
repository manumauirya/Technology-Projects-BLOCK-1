| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU |Processes instructions and performs calculations |Model, number of cores, clock speed.|
RAM |Temporarily stores data used by running programs.|Capacity (GB), DDR type, speed (MHz).|
| Storage|Stores the operating system, applications, and files.| SSD/HDD, capacity (GB or TB).|
| Motherboard |Connects all computer components together.|Model, chipset, supported RAM.|
| Power Supply |Converts electricity and supplies power to components.|Wattage (W), efficiency rating.|
| Cooling |Removes heat to prevent overheating.|Fan size, cooler type.|

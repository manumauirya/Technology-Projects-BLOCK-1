- In one paragraph: interpretation vs compilation.

  
  Interpretation and compilation are two ways of running a program. Interpretation means the computer runs the code line by line.
   Compilation means the whole code is changed into machine code before running it. Interpreted programs are usually easier to test
   and fix, while compiled programs usually run faster. For example, Python uses an interpreter, while C is normally compiled before
   it runs.
